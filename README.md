# 🍱 午餐轉盤

不知道午餐吃什麼？打開網頁、找附近店家、轉一下轉盤讓命運決定！

## 功能
- **地圖**：OpenStreetMap + Leaflet，可用 GPS 定位、輸入地址，或直接點地圖設定位置
- **搜尋附近店家**：可選範圍（300m～2km）、類型（預設「吃正餐」，排除咖啡廳與手搖飲料店；也可選全部／餐廳／速食小吃／咖啡廳）與關鍵字篩選
- **四種選餐遊戲**（適合跟朋友一起玩）：
  - 🎡 轉盤：轉到哪家吃哪家
  - 🔫 俄羅斯輪盤：6 個彈巢各放一家店，輪流扣扳機，「喀」淘汰、「砰」就吃這家
  - 🎲 骰盅：搖骰盅、開盅，三顆骰子點數總和決定吃哪家（每家機率相同）
  - 🃏 撲克牌：每人翻一張，全部翻開後點數最大的決定午餐
- **價位篩選**：每人 $250 以內／$250–750／$750 以上，店名旁顯示估計的每人平均價格（依連鎖品牌、店名關鍵字與料理類型推估）
- **自己加店家**：可手動輸入，或按「試玩範例店家」直接開玩
- **分店標示**：店名旁顯示分店名（沒有分店名時顯示所在路名），Google 連結會用完整地址直接定位到該分店
- **Google 評價**：每家店都有「⭐ Google 評價」按鈕，會連到 Google 地圖看評分與評論；另有「🚶 導航過去」

## 使用方式
只有一個 `index.html`，不需要 API 金鑰：
- 直接用瀏覽器開啟，或
- 部署到 GitHub Pages（Settings → Pages → 選擇分支）

> 註：「使用我的位置」需在 HTTPS（例如 GitHub Pages）或 localhost 下才能使用。

## 資料來源
- 店家資料：OpenStreetMap（透過 Nominatim，每秒 1 次查詢，結果會逐步顯示）
- 地址搜尋：Nominatim
